# AI PM Daily Practice

Working folder for the daily practice from the [prep plan](../GOOGLE_AI_PM_INTERVIEW_PREP_PLAN.md). Goal: build real model intuition, eval skill, and product taste through short daily reps, with evidence you can talk about in the interview.

## Structure

| Path | Purpose | Attribute |
|------|---------|-----------|
| `daily-logs/` | One file per day, copied from `TEMPLATE.md` | 1, 2 |
| `vibe-benchmark.md` | 5-10 prompts rerun on every new model | 1 |
| `model-notes/` | One "personality" note per model | 1 |
| `evals/` | Eval sets with rubrics and scored results; see `evals/summary.md` | 3 |
| `product-critiques/` | Short critiques of AI products | 5 |
| `model-swap-note.md` | How a better model drops in with minimal rework | 4 |
| `60-20-20-plan.md` | Roadmap split into works / almost works / ambitious | 6 |
| `story-bank.md` | Interview stories tagged to attributes | All |

## Weekly rhythm (about 60 min a day)

| Day | Activity |
|-----|----------|
| Mon | Model play + log (attribute 1) |
| Tue | Eval work: prompts and rubric (attribute 3) |
| Wed | Data reading or API prototype (attribute 2) |
| Thu | Product critique + abstract-the-request drill (attribute 5) |
| Fri | 60-20-20 and "what changed" note (attributes 4, 6) |
| Weekend | Mock interview / story practice |

## How to start today

1. Copy `daily-logs/TEMPLATE.md` to `daily-logs/YYYY-MM-DD.md`.
2. Fill in the vibe benchmark prompts in `vibe-benchmark.md` and run them.
3. Log what you saw. Commit at the end of the day.
